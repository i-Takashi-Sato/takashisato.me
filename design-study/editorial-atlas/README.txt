THE PROPER ENDING INDEX — EDITORIAL ATLAS DESIGN STUDY
========================================================
A new six-page responsive site for design evaluation, not a production deployment.
The purpose is to demonstrate an independent visual direction: ivory editorial surfaces,
an interpretive three-part diagram, meticulous research records, and a dark Part III.

Files: index.html, papers/index.html, papers/part1.html, papers/part2.html,
papers/part3.html, about.html, site.css.

Research identities, title, SSRN IDs, DOIs, v6.2 version, page counts, PDF sizes
and SHA-256 identifiers correspond to the canonical GitHub metadata read on
November 16, 2026. Paper body text is an editorial *synopsis*, not a substitute
for the actual PDFs or full original website pages. The underlying archive
content has not been edited. External PDF/SSRN/DOI links point to real records.

No claims of awards, peer-review endorsement or established field effectiveness.
Schematic illustrations do not depict empirical data.
Designed for no-JS, keyboard, touch, responsive layout and reduced motion;
browser screenshots and static link tests to follow.
