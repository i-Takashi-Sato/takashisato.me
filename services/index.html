When work depends on memory, it breaks quietly.

01

担当者が休む、辞める、異動する。その瞬間に止まる業務は、まだ組織の仕組みになっていません。

02

確認漏れ、教育のばらつき、引き継ぎの曖昧さは、能力不足ではなく、記録されていない運用から発生します。

03

業務設計室が設計するのは、誰が担当しても同じ手順で確認できる、記録可能な業務の構造です。

Service Fields

属人化した判断、確認の抜け、引き継ぎの曖昧さを、日々確認できる文書と表に整理します。作業代行ではなく、運用後に読み返せる形を設計します。

01

業務手順書・SOP設計

Operational Documentation Design

属人化した作業と判断を、誰でも実行・確認できる手順へと再設計します。業務フロー整理、SOP、手順書、チェックリストを設計・制作します。

  • 業務フロー整理
  • SOP / 手順書
  • 確認チェックリスト
  • 引き継ぎ資料
  • 納品形式：PDF / Word / Google Docs 等
02

業務確認・管理表設計

Operational Control Sheet Design

日次・週次・月次の確認、KPI記録、進捗管理に用いる管理表を設計します。ExcelおよびGoogleスプレッドシートによる運用を前提に、記録と確認の流れを定義します。

  • Excel / Google Sheets
  • 日次・週次・月次確認表
  • KPI記録
  • 進捗管理表
  • 納品形式：Excel / Google Sheets / PDF 等
03

採用・教育・評価文書設計

HR Documentation Design

採用基準、教育手順、評価項目を文書として整備します。スタッフの増加や業務の引き継ぎ時に、判断と教育のばらつきを抑える資料群を設計します。

  • 採用基準
  • 教育手順
  • 評価項目
  • 試用期間確認表
  • 納品形式：PDF / Word / Google Docs 等

Design Process

正式な依頼文や完成した資料がなくても構いません。現在の運用、既存メモ、困っている場面から、設計範囲を整理します。

01

確認

現在の業務、困っていること、作りたい資料、既存資料の有無を確認します。

02

範囲整理

手順書、チェックリスト、管理表、採用・教育資料のどこまでを設計するかを整理します。

03

初稿作成

ヒアリング内容と既存資料をもとに、運用で使える文書・表の初稿を作成します。

04

修正

確認後、実際の運用に合わない箇所、言葉の粒度、項目の過不足を修正します。

05

納品

PDF、Word、Excel、Googleスプレッドシート等、使用目的に合わせた形式で納品します。
