Colophon

Overview

The archive is designed for legibility, evidence traceability, and long-term survival—not for product conversion or decorative spectacle.

Architecture

Every public page is pre-rendered static HTML from a small source model: canonical research metadata, document chrome, page renderers, source styles, and progressive-enhancement modules. Build output remains one shared stylesheet and one script; the stylesheet is preloaded and applied without an inline style block. There is no framework runtime, remote font request, client-side router, account system, or third-party UI package.

Typography & material

Primary interface and reading typography uses self-hosted Inter Variable with system fallbacks. The author chamber may use editorial serif typography, the approved paper material and supplied signature. The research pages use a light reading field, measured typographic hierarchy and research-linked geometry. Functional diagrams remain semantic HTML and CSS so their content is selectable, responsive, and printable.

Interaction

The archive preserves native pointer behavior. Section orientation and paper-specific state motion enhance the pre-rendered research record without replacing navigation or citations. Touch, keyboard, no-JavaScript, and reduced-motion users retain the scholarly record; the optional conceptual probe is not an operational decision engine.

Accessibility

Landmarks, heading order, skip links, keyboard-visible focus, 44-pixel navigation targets, reduced-motion behavior, high-contrast text, and print styles are part of the base system.

Preservation

SSRN remains the primary external research record. Versioned local PDFs are preserved with file size and SHA-256 recorded on each paper page and in research-index.json.

Build

The site is generated by a dependency-free Python script and checked by a repository validator in continuous integration. The current scholarly record is version 6.3, revised 28 November 2026. Earlier PDFs and citations remain preserved. The visual identity was revised on 23–24 November 2026. On 24 November 2026 the website clarified computational provenance and recorded a subsequent author-side re-execution of the recovered v5.9 finite-state checker; the preserved manuscripts and their reported results were not changed.
