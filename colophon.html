Colophon

Overview

The archive is designed for legibility, evidence traceability, and long-term survival—not for product conversion or decorative spectacle.

Architecture

Every public page is pre-rendered static HTML. The interface uses one base stylesheet, one progressive interaction layer, one dependency-free enhancement script, and a small analytics adapter. There is no framework runtime, client-side router, account system, or third-party UI package. Research content remains complete before JavaScript runs.

Typography & material

The interface pairs Newsreader for editorial display, Inter for navigation and long-form screen text, and Mea Culpa as a deliberately scarce calligraphic signature. Those three families are self-hosted under the SIL Open Font License. The public-domain Aoyagi Kouzan Font T is used only for the decorative 序・破・急 stage marks and may be requested from the Leafscape webfont CDN; if unavailable, a local Japanese Mincho fallback preserves the composition. Grain, paper, and brushed metal retain distinct material roles, while functional diagrams remain semantic HTML and CSS so their content is selectable, responsive, and printable.

Jo / Ha / Kyu

The trilogy uses 序・破・急 as stage notation rather than Roman numerals. Part I is quiet and measured, Part II allows controlled displacement, and Part III converges toward closure. The marks sit behind the paper hero as low-opacity ultramarine ink and never carry research meaning by themselves.

Interaction

Fine-pointer devices receive a difference-blended cursor with velocity response, proximity-aware magnetic controls, pointer-position lighting, relational hover, scroll-linked material drift, section-aware reading orientation, and cross-document view transitions. The interaction grammar is enter, approach, engage, release, settle. The footer deliberately reduces visual energy as the page reaches Proper Ending. Touch, keyboard, reduced-motion, forced-colors, and print retain the complete archive without those effects.

Accessibility

Landmarks, heading order, skip links, keyboard-visible focus, 44-pixel navigation targets, reduced-motion behavior, high-contrast text, forced-colors fallbacks, and print styles are part of the base system. Decorative stage marks are removed where they would interfere with those modes.

Preservation

SSRN remains the primary external research record. Versioned local PDFs are preserved with file size and SHA-256 recorded on each paper page and in research-index.json.

Build

The site is generated by a dependency-free Python script and checked by a repository validator in continuous integration. The current visual interaction layer was revised on 24 August 2026; the research papers remain version 6.2 dated 23 August 2026.
